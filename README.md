# vellum-privacy

**Vellum 개인정보 처리방침의 공개 판.** GitHub Pages 로 서비스한다.

👉 https://p1zzal.github.io/vellum-privacy/

---

## 🔴 이 저장소만 고치지 말 것

원본은 **비공개 저장소의 `PRIVACY.md`** 다. 이 저장소의 `index.html` 은 그것을
HTML 로 옮긴 것이고, **셋이 항상 같은 말을 해야 한다:**

| | 어디 |
|---|---|
| 원본 | 비공개 저장소 `PRIVACY.md` |
| 공개 판 | 여기 `index.html` |
| App Privacy(영양 성분표) | App Store Connect — 답안은 `packages/mobile/APPSTORE.md` §9-2 |

⚠️ **어긋나는 것 자체가 App Store 거부 사유다.** 서버가 저장하는 것을 바꿨으면
세 곳을 함께 고치고, 본문 맨 위의 최종 수정일도 바꾼다.

## 설정 (한 번만)

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)` → Save.
1~2분 뒤 위 주소가 열린다.

## 왜 저장소가 따로인가

본 저장소는 서명 키·서버 자료가 들어 있어 **공개할 수 없다.** 그런데 App Store
Connect 는 처리방침을 **공개 URL** 로 요구한다. 그래서 이 한 장만 떼어 둔다.
